GarminDesk — installation

1. Drag GarminDesk.app onto Applications.
2. Eject the disk, then open GarminDesk from Applications.
3. Sign in normally to Garmin Connect under Garmin account.
4. Under Widgets, choose Colorful, Light, or Dark and preview each widget.
   No profiles or assignments are needed.
5. Right-click the desktop → Edit Widgets → GarminDesk. Add Summary, Day,
   Sport, Sleep, or Training calendar in the size you want.
   A large Summary combines the main measurements in one layout. Choose
   its measurements under Widgets; add Sleep or Training for more detail.

GarminDesk runs in the menu bar without a Dock icon. Click the small watch
icon at the top right for settings, refresh, or quit. Clicking a widget opens
its corresponding view. Closing the window keeps synchronization running;
⌘Q quits. Choose the interface language under General.

Measurement cards show a short interpretation. Click the information button
for the meaning, personal ranges when available, and the reading time.

No Python, Homebrew, extra libraries, or terminal setup is needed. The app
connects directly to Garmin Connect using system WebKit. New readings require
internet access and a watch synced with Garmin Connect.

For a trusted app that macOS identifies as an unknown developer or not
notarized, first try opening it, then use System Settings → Privacy & Security
→ Open Anyway → Open. Enter a Mac password only in the system prompt if asked.
This is not for malware or damaged-app warnings; managed Macs may disallow it.
Apple instructions: https://support.apple.com/102445

Choose arm64 for Apple Silicon or x86_64 for an Intel Mac. Target: macOS 14+.
See the release notes for verified macOS versions:
https://github.com/sifushka322/garmin-widget-macos/releases
