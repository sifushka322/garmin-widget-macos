GarminDesk 0.4.0 — установка / installation

РУССКИЙ
1. Перетащите GarminDesk.app на значок Applications («Программы»).
2. Извлеките диск и откройте GarminDesk из «Программ».
3. В разделе «Аккаунт Garmin» выполните обычный вход Garmin Connect.
4. В «Профили виджетов» настройте показатели и назначьте профили четырём
   видам виджетов.
5. Правой кнопкой на рабочий стол → «Изменить виджеты» → GarminDesk.
   Выберите вид и размер, затем добавьте виджет.

GarminDesk открывается обычным окном и находится в Dock. Нажатие виджета
открывает приложение с его профилем. Закрытие окна оставляет синхронизацию
работающей; ⌘Q завершает приложение. Язык меняется в разделе «Основные».

Python, Homebrew, библиотеки и терминал для установки не нужны. Приложение
использует системный WebKit и подключается напрямую к Garmin Connect.
Для новых измерений нужны интернет и синхронизация часов с Garmin Connect.

Если macOS сообщает о неизвестном разработчике или отсутствии заверения,
после попытки открытия доверенной копии используйте «Системные настройки» →
«Конфиденциальность и безопасность» → «Всё равно открыть» → «Открыть».
Пароль Mac вводите только в системном диалоге, если система его запросит.
Это действие не предназначено для предупреждений о вредоносном или
повреждённом приложении; на управляемом Mac оно может быть недоступно.
Справка Apple: https://support.apple.com/102445

Выберите пакет arm64 для Apple Silicon или x86_64 для Intel Mac.
Целевая система — macOS 14+.
Проверенные версии macOS перечислены в описании выпуска:
https://github.com/sifushka322/garmin-widget-macos/releases

ENGLISH
1. Drag GarminDesk.app onto Applications.
2. Eject the disk, then open GarminDesk from Applications.
3. Sign in normally to Garmin Connect under Garmin account.
4. Under Widget profiles, choose metrics and assign profiles to the four
   widget kinds.
5. Right-click the desktop → Edit Widgets → GarminDesk. Choose a kind and
   size, then add the widget.

GarminDesk is a regular windowed app with a Dock icon. Clicking a widget
opens the app with its profile. Closing the window keeps synchronization
running; ⌘Q quits. Choose the interface language under General.

No Python, Homebrew, extra libraries or terminal setup is needed. The app
connects directly to Garmin Connect using system WebKit. New readings require
internet access and a watch synced with Garmin Connect.

For a trusted app that macOS identifies as an unknown developer or not
notarized, first try opening it, then use System Settings → Privacy & Security
→ Open Anyway → Open. Enter a Mac password only in the system prompt if asked.
This is not for malware or damaged-app warnings; managed Macs may disallow it.
Apple instructions: https://support.apple.com/102445

Choose arm64 for Apple Silicon or x86_64 for Intel Mac. Target: macOS 14+.
See the release notes for verified macOS versions:
https://github.com/sifushka322/garmin-widget-macos/releases
