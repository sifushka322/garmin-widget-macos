# GarminDesk 0.3.0 — build 9

## Changes

- **A regular Mac app:** one full window and a Dock icon. **Overview**, **Widget profiles**, **Garmin account**, and **General** bring data and settings together. The menu-bar popover is removed.
- Clicking a system widget opens the main window with its assigned profile. If the connection or profile is not set up yet, the app opens the corresponding section.
- Closing the window keeps synchronization running; **⌘Q** quits the app.
- The newly selected icon shows a round watch with a mint activity ring.
- Customizable profiles for four widget kinds, Russian/English and system-language selection, recent completed activities, and the published calendar remain available.

## Validation of this version

**0.3.0 build 9 was installed and verified on Apple Silicon, macOS 26.6.2.**

- The regular window and all four sections were checked visually and through macOS Accessibility. **⌘2** navigation, **⌘W** close, and **⌘0** reopen work.
- The saved Garmin session and profiles survived the update. Manual **Refresh** completed successfully. **74 checks passed.**
- Built, installed, and ZIP-extracted copies report **0.3.0 (9)**. SHA-256 hashes for the host executable, WidgetKit executable, and icon match across copies; the icon also matches the selected resource in `Resources`. `LSUIElement` is absent.
- All copies passed `verify-release`: bundle structure, ad-hoc signatures, native-only contents, and dependencies limited to system libraries. Packages contain no Python/Connector, private runtime files, or embedded absolute paths to the developer's home directory.
- **The DMG passed its `hdiutil` CRC check; ZIP and DMG passed SHA-256 verification.**

Routing from a system widget to the new window was implemented and reviewed in code; **an actual widget click after the 0.3.0 update was not separately tested**. Other Macs, other macOS versions, and Intel were not verified. Targeting macOS 14+ does not imply a runtime test on macOS 14.

Earlier extended background-refresh and live-system-widget checks apply to **0.2.0 build 7** and remain in the [validation history](../validation.md). They are not presented as repeated validation of these scenarios in 0.3.0.
