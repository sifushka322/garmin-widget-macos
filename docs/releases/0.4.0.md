# GarminDesk 0.4.0 — build 10

## Что изменилось

- Новый дизайн обзора и виджетов: цветовые темы по типу показателя, крупные значения и компактные единицы измерения.
- На рабочем столе убраны повторяющиеся даты, время проверки и служебные заголовки. При проблеме появляется одно короткое предупреждение.
- До подключения Garmin не показываются вымышленные показатели. Если новых измерений нет, сохраняются последние реальные значения; в приложении доступна их дата.
- Сон и завершённые ночные записи не помечаются устаревшими только из-за задержки синхронизации. Шаги и Body Battery показывают последние полученные данные, а не трансляцию с часов.
- Текущий пульс удалён из доступных показателей; пульс в покое сохранён. Старые профили обновляются автоматически.
- Исправлены обработка частичных ответов Garmin, смена аккаунта, повреждённые настройки и расположение длинных значений в виджетах.
- Добавлен готовый пакет для Intel Mac.

## Скачать и обновить

| Mac | Установщик | Альтернативный архив |
| --- | --- | --- |
| Apple Silicon (M1 и новее) | `GarminDesk-0.4.0-arm64.dmg` | `GarminDesk-0.4.0-arm64.zip` |
| Intel | `GarminDesk-0.4.0-x86_64.dmg` | `GarminDesk-0.4.0-x86_64.zip` |

Для каждой архитектуры приложен файл `-SHA256.txt` с контрольными суммами.

Для обновления завершите GarminDesk через **⌘Q**, откройте подходящий DMG и замените приложение в **Applications («Программы»)**. Затем запустите GarminDesk. Удалять локальные настройки или данные приложения не требуется.

Целевая система — macOS 14+. Python, Homebrew и дополнительные библиотеки не нужны. Пакеты используют ad-hoc подпись без Developer ID и notarization. При предупреждении о неизвестном разработчике доверенную копию можно открыть через стандартный пункт macOS **«Всё равно открыть»**. [Инструкция установки](https://github.com/sifushka322/garmin-widget-macos/blob/main/docs/distribution.md).

## Проверка выпуска

Публикация выполняется только после успешного полного CI-прогона для Apple Silicon и Intel: нативные тесты, JavaScript/Python, синтетические снимки интерфейса, изоляция виджетов, архитектура и версии приложения/расширения, подписи и системные зависимости. ZIP и DMG собираются из проверенных приложений. Перед публикацией контрольные суммы всех загруженных файлов сопоставляются с исходными пакетами.

Сборка и тесты выполняются на удалённых macOS 26 runners. Реальный вход в Garmin, размещение/обновление системных виджетов и совместимость с macOS 14 отдельно не проверены в этом выпуске. Синтетические снимки не заменяют эти проверки. Приложение на Mac владельца для выпуска не запускалось и не обновлялось.

## English

Version 0.4.0 redesigns the dashboard and desktop widgets around clear values and semantic colors. Routine polling timestamps and duplicate labels are removed; a concise warning appears when attention is needed.

No invented readings appear before connection. Last real values survive missing or delayed data, completed sleep/nightly records retain their meaning, and instantaneous heart rate is removed because Connect cannot provide a reliable live reading. Resting heart rate remains available. Account-cache isolation and damaged-preference handling are improved.

Choose **arm64** for Apple Silicon or **x86_64** for Intel. Quit GarminDesk, replace the app in Applications using the matching DMG, then reopen it. Both architectures include ZIP alternatives and SHA-256 files. Packages target macOS 14+ and are ad-hoc signed, without Developer ID or notarization.

Publication requires passing hosted CI for both architectures and matching uploaded asset checksums. Live Garmin sessions, real desktop WidgetKit behavior and macOS 14 runtime compatibility were not retested for this release.
