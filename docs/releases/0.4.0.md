# GarminDesk 0.4.0 — build 10

## Changes

- A redesigned overview and widgets with colors that reflect metric categories, prominent values, and compact units.
- Duplicate dates, polling timestamps, and diagnostic headings are removed from desktop widgets. A short warning appears when something needs attention.
- No invented readings appear before Garmin is connected. When new readings are missing, the last real values remain; their dates are available in the app.
- Sleep and completed overnight records are not marked stale solely because synchronization is delayed. Steps and Body Battery show the latest available data, not a live stream from the watch.
- Instantaneous heart rate is removed from available metrics; resting heart rate remains. Existing profiles migrate automatically.
- Fixes for partial Garmin responses, account switching, damaged preferences, and long values in widgets.
- A ready-to-use package for Intel Macs is now available.

## Downloads and upgrading

| Mac | Installer | Alternative archive |
| --- | --- | --- |
| Apple Silicon (M1 and later) | `GarminDesk-0.4.0-arm64.dmg` | `GarminDesk-0.4.0-arm64.zip` |
| Intel | `GarminDesk-0.4.0-x86_64.dmg` | `GarminDesk-0.4.0-x86_64.zip` |

Each architecture includes a `-SHA256.txt` checksum file.

To upgrade, quit GarminDesk using **⌘Q**, open the matching DMG, and replace the app in **Applications**. Then reopen GarminDesk. There is no need to delete local preferences or app data.

The target is macOS 14+. Python, Homebrew, and additional libraries are not required. Packages use ad-hoc signing without Developer ID or notarization. If macOS warns about an unidentified developer, a trusted copy can be opened using the standard **Open Anyway** option. [Installation instructions](https://github.com/sifushka322/garmin-widget-macos/blob/main/docs/distribution.md).

## Release validation

The original 0.4.0 workflow made the release public after a successful full CI run for Apple Silicon and Intel: native tests, JavaScript/Python, synthetic interface snapshots, widget isolation, app/extension architecture and versions, signatures, and system dependencies. ZIP and DMG files were built from verified apps; uploaded file checksums were compared with the original packages.

Builds and tests ran on hosted macOS 26 runners. Before publication, live Garmin sign-in, system-widget updates after replacing the app, and macOS 14 compatibility were not separately tested. The app on the owner's Mac was not launched or upgraded as part of that validation.

**Known upgrade issue, discovered September 16, 2026:** with 0.4.0 build 10 already installed, the gallery could retain the old icon and old snapshots while an extension process continued running from before the package replacement. After local re-registration and extension/NotificationCenter restarts, the new watch icon and some previews were confirmed in the live gallery. This demonstrates recovery on one Mac, not a fix for normal upgrades for all users. [Incident analysis and upgrade validation](../widget-upgrade-validation.md).

For future candidates, CI prepares only a verified **draft**. Publishing it and marking it latest requires a successful normal upgrade test on a Mac with a graphical session, following the [publication checklist](../publication-checklist.md). Release descriptions were later translated to English; the already published downloadable assets were not replaced.
