# GarminDesk 0.6.0

**Stable release · build 15 · macOS 14+**

GarminDesk keeps your Garmin Connect readings close at hand with a quiet menu-bar app and five desktop widget types: Summary, Day, Sport, Sleep, and Training calendar.

## Clearer readings

- A consistent card grid puts the measurement first, followed by a short interpretation and its date. An information button explains what each metric means.
- Training load uses Garmin's available personal context. Overnight HRV and weekly HRV status are explained separately.
- Completed sleep and sport readings keep their original dates. After an upgrade, a bounded lookup can recover yesterday's missing completed records from the connected account.
- All twelve languages include metric explanations, estimate labels and accessibility descriptions.

## More dependable updates

- Each data group retries independently, so a delayed endpoint does not hold back successful readings. Slow batches publish completed data as it arrives.
- Body Battery checks the daily summary as well as timed graph samples. When enough recent samples exist, an optional local linear estimate changes between synchronizations and is marked with `≈`. It is an estimate from recorded samples, rather than a Garmin-provided forecast.
- Saved readings survive reconnecting the same account and interrupted cache writes. Account boundaries remain separate.
- Display timers stop when their window or metric is hidden. Widget updates avoid duplicate writes and use finite timelines; macOS controls their actual redraw timing.

## Getting started

Download the DMG for **Apple Silicon (`arm64`)** or **Intel (`x86_64`)**, move GarminDesk to Applications, and sign in to Garmin Connect. No Python, Homebrew or additional libraries are required.

Use the monochrome watch icon in the menu bar for refresh, settings and Quit. Closing the window keeps synchronization running. Add desktop widgets through **Edit Widgets → GarminDesk**.

Packages use ad-hoc signatures. If macOS asks for developer verification, use **System Settings → Privacy & Security → Open Anyway** for your trusted download. [Apple's opening instructions](https://support.apple.com/102445).
