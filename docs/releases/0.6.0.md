# GarminDesk 0.6.0

Build 15 is the final-audit candidate. GitHub Actions prepares private draft
packages for Apple Silicon and Intel after automated checks pass. The public
release remains on hold until the candidate has been reviewed.

## Changes

- GarminDesk runs from a monochrome watch icon in the menu bar, without a Dock
  icon. Closing its window keeps background synchronization running.
- Metric cards use a uniform grid, consistent spacing and a clear value-first
  layout. Detailed explanations are available through the information button.
  Retained readings keep their dates without repeated dashboard banners.
- Metric explanations, Body Battery estimate copy and accessibility context are
  localized in all twelve supported languages.
- Independent sync retries prevent one failing endpoint from blocking healthy
  groups. Slow batches expose completed readings while bounded retry schedules
  avoid repeated requests to a failing endpoint.
- Server rate-limit and authentication signals survive response-body failures.
  Closing an interactive sign-in cancels its pending work.
- Reconnecting the same account preserves saved readings. Interrupted cache
  writes reconcile newer data without mixing accounts.
- If an older installation has no account-owned saved night or sport reading,
  the app can retrieve yesterday's completed record from the connected account.
  Historical values keep their dates and never replace today's measurements.
  Recovery is bounded and does not repeatedly scan historical days.
- Body Battery uses both the latest summary scalar and timed graph samples.
  Its optional local linear estimate displays `≈`, expires after its bounded
  horizon and does not alter the actual sample. This is not a verified Garmin
  forecast. macOS controls actual widget display cadence.
- Display schedules are finite and stop for hidden windows or hidden metrics.
  Normal synchronization avoids duplicate widget-file writes and reloads.

## Validation

New regressions cover partial failures, retry gates, cache write interruption,
authentication and response limits, all localization keys and parameters,
window visibility, estimate expiry and uniform card geometry. Filled UI fixtures
cover all languages, and information panels cover all 25 metrics in all twelve
languages. Results will be recorded after the exact candidate completes CI and
on-device review; this document does not claim unperformed checks passed.

The earlier [local build-12 audit](../audit-0.6.0.md) is historical evidence for
the initial candidate, not validation of these final changes.

Packages target macOS 14+, use ad-hoc signatures and are not Apple-notarized.
No Python or Homebrew is required.
