# GarminDesk 0.7.1

**Build 17 · macOS 14+ · Apple Silicon and Intel**

## Cleaner widgets

- Keep one labeled scale for the main reading; supporting readings no longer repeat gauges and generic explanations.
- Use consistent number sizes, including sleep. Sleep and its stages use an easy-to-scan hours:minutes format such as **8:04**.
- Remove repeated assessments and duplicate dates while preserving historical context, connection notices, detailed help and VoiceOver descriptions.
- Include the previous candidate's aligned dashboard cards, matching-night sleep assessments and clearer training-load context.

## Optional automatic sign-in

Open **Garmin account → Automatic sign-in**, enter your login and password once, and choose **Save for automatic sign-in**. Credentials stay in the device-local macOS Keychain, outside preferences, widgets and release packages.

The app first tries to restore its saved website session. If credentials are needed, it can submit the ordinary Garmin sign-in form once. A verification code, security challenge or rejected password still requires your input. Forgetting the saved login keeps the current session; disconnecting removes both. After reauthentication, account identity is checked before accepting measurements.

## Download and install

Choose the **arm64 DMG** for Apple Silicon or the **x86_64 DMG** for an Intel Mac. Drag GarminDesk.app to Applications. ZIP alternatives and SHA-256 checksums are included. No Python, Homebrew or extra libraries are required.

Packages use an ad-hoc signature without Apple notarization. See the [installation guide](https://github.com/sifushka322/garmin-widget-macos/blob/main/docs/distribution.md).

## Validation

The local application upgrade preserved settings and the connected session. Automated coverage includes synchronization, account isolation, authentication-form boundaries, localization, synthetic widget rendering and package verification. GitHub Actions checks both architectures and older macOS runtimes before publishing the packages.

Password-based automatic recovery has not yet been exercised with a real Garmin account. Exhaustive testing of existing desktop widgets and all gallery variants after upgrading the exact downloaded release packages has not been completed. The [publication validation report](https://github.com/sifushka322/garmin-widget-macos/blob/main/docs/releases/validation/0.7.1-publication.md) records the exact candidate, packages and remaining limits.
