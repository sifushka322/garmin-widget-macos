# GarminDesk 0.5.0

Five widget types and simpler setup, with no profiles or assignments.

- **Summary:** one unified layout with a preferred main measurement and supporting values. Choose its measurements in Widgets settings; only selected, available readings appear. Large shows up to seven measurements. The calendar has its own widget.
- **Day, Sport, Sleep, and Training calendar:** focused views in small, medium, and large sizes. Training shows completed and scheduled activities in a week or month calendar.
- **Colorful, Light, and Dark:** one setting changes every widget’s backgrounds and text contrast, with an immediate app preview.
- **Filled gallery previews:** localized Demo badges clearly identify sample readings and schedules. App previews use samples until relevant real data is available. Desktop widgets continue to show real data or a connection/waiting state.
- **Twelve languages:** English, Russian, German, French, Spanish, Italian, Brazilian Portuguese, Dutch, Polish, Japanese, Korean, and Simplified Chinese.
- **Corrected icon packaging:** removes unintended translucency that could cause an extra gray system tile. The artwork is unchanged. Public documentation is now in English.

Existing widget kind identifiers are preserved and Day is added. Connection, cached readings, language, appearance, and refresh settings migrate. Old profiles, assignments, and selections are replaced; Summary starts with editable defaults.

Choose **arm64** for Apple Silicon or **x86_64** for Intel. Install the DMG or ZIP app in Applications. No Python, Homebrew, or terminal setup is required. Packages target **macOS 14+**, use **ad-hoc signatures**, and **are not Apple-notarized**.

Automated build and package verification: [release workflow](https://github.com/sifushka322/garmin-widget-macos/actions/runs/35105278274).
