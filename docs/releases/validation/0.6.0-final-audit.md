## Changes found and verified during the audit

- Synchronization: independent retries, bounded backoff, global authentication/rate-limit handling, partial publication of successful groups, cancellation of interactive sign-in, monotonic batch deadlines and interrupted cache-write recovery.
- Data ownership: account-owned cache migration, a strictly bounded previous-day recovery queue, durable attempted-request tracking, restart and day-rollback behavior, and preserved source dates. Current readings outrank recovered records.
- Body Battery: summary/report reconciliation, scalar readings without invented timestamps, recent-sample linear estimates, bounded expiry and separation of actual versus estimated values.
- Lifecycle and efficiency: menu-bar accessory policy, closing and reopening windows, hidden-window scheduling, finite widget timelines and avoiding duplicate snapshot publication.
- Presentation: consistent metric-card dimensions, dated historical readings, appropriate training/HRV context, twelve localization catalogs, metric explanations and accessibility text.
- Distribution: host/extension identity, nested signatures, target architecture, dependency checks, package contents and checksums. Exact packaged binaries are tested separately from native source tests.
