## Executed local checks

- All thirteen model suites passed: 20,118 checks, including twelve-language localization, payload normalization, metric explanations, fixed-widget migration, synchronization policy, provenance and display scheduling.
- After the final near-goal rounding correction, MetricIndicatorTests passed 306 checks (five additional regression checks). Below-goal progress cannot display 100%; exact and exceeded goals retain their localized percentages.
- GarminWebBoundaryTests: 49 checks; AppStoreSyncTests: 246 checks; BrandIconTests: 12 checks.
- MenuBarLifecycleTests: 52 checks passed twice after fixing a reproduced retained-window reopen bug. A retained window did not always emit an occlusion notification, and a queued forced-hidden event could pause an already reopened window. The new rapid close/reopen regression passes alongside the original close, minimize, hidden-window and background-sync checks. The first Intel/macOS 15 CI attempt exposed an incorrect test assumption that every open window is unoccluded; the regression now compares against the actual presentation state, retaining the requirement that occluded windows pause their timers.
- Legacy Python suite: 36 tests; JavaScript contracts: 84 checks; release-draft guards: 4 tests; release-promotion guards: 37 tests; runtime-compatibility contract tests: 7 tests. All passed without live Garmin requests in the test suites.
- Synthetic rendering completed: 1,254 widget PNGs, 1,036 app PNGs and 45 calendar PNGs. App geometry assertions passed for the fixed 192/176-point cards, equal row dimensions and balanced four-card layouts. Russian 780/960/1100-point app layouts and small/medium/large widgets were visually reviewed in light/dark appearances, including retained sleep, load ratios, personal ranges, dates and notices. The final percentage correction changes only model text; its targeted regression was rerun after the visual matrix.

Logs and synthetic fixtures are local under `build/audit/release-0-7/` and `build/audit/release-0-7-ui/`. They contain no exported live account screenshots.

## Scope of evidence

This is a local app upgrade and package-validation report, not a completed publication-approval report for every existing desktop widget. All five gallery kinds in all three sizes, every existing desktop instance and exact downloaded CI-asset upgrades have not been exhaustively checked here. Private readings and screenshots were not published.

GitHub Actions associated with the release commit separately builds Apple Silicon and Intel packages and runs the native and packaged-runtime checks on older supported macOS versions. Its successful release job prepares a six-asset draft. This report does not predeclare those remote results or authorize public promotion; the requested new release is prepared as a draft.
